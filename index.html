How to use these notes

  1. Read the statement first. Definitions sit in blue boxes, theorems in violet ones, and worked numbers in green.
  2. Open the proof only after trying it. Each derivation is folded under a “Proof” or “Derivation” line.
  3. Move the sliders. Every figure recomputes from the formula in the text; hover or touch a curve to read values.
  4. Check yourself. Chapters end with a few questions that give immediate feedback.
Accessibility

All controls are native form elements and work from the keyboard (Tab to reach a slider, arrow keys to change it). Each figure has a text description and a live readout of the key numbers, so the result of a change is announced without needing the plot. A light and a dark theme are available from the button in the header, and animations only run when you press Play.

Units

Energies are in eV, lengths in nm or cm as is customary for devices, and $k_BT = 25.85$ meV at 300 K. Material parameters are textbook values for illustration, not design data.
